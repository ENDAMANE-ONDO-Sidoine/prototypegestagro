Webhooks

Les webhooks permettent à l'API GestAgro de notifier automatiquement votre application lorsqu'un événement important se produit, sans que vous ayez à interroger constamment l'API.

Comment fonctionnent les webhooks ?

Lorsqu'un événement se produit sur la plateforme (nouvelle commande, changement de statut, etc.), l'API envoie une requête HTTP POST à l'URL que vous avez configurée.

  1. Vous configurez une URL de webhook dans votre compte
  2. Un événement se produit sur la plateforme
  3. L'API envoie une notification POST à votre URL
  4. Votre serveur traite l'événement

Webhook Paiements (Providers)

Les prestataires enverront des callbacks vers l’endpoint suivant :

POST {{ api_base_url }}payments/webhook/{provider}/
Content-Type: application/json
X-Webhook-Signature: sha256=...

{
  "event_type": "payment.succeeded",
  "transaction_id": "AM-TXN-789012",
  "order_reference": "ORD-A1B2C3D4",
  "status": "succeeded",
  "amount": "50000.00",
  "currency": "XAF",
  "timestamp": "2025-11-04T10:05:00Z"
}

La signature est vérifiée côté API. Les événements sont traités de façon idempotente.

Configuration

1. Créer un webhook

POST {{ api_base_url }}webhooks/
Authorization: Bearer YOUR_ACCESS_TOKEN
Content-Type: application/json

{
  "url": "https://votre-domaine.com/webhooks/gestagro",
  "events": ["order.created", "order.updated", "payment.completed"],
  "secret": "votre-secret-securise",
  "active": true
}

2. Vérifier votre URL

Après la création, l'API enverra une requête de vérification à votre URL pour s'assurer qu'elle est accessible. 

POST https://votre-domaine.com/webhooks/gestagro
Content-Type: application/json
X-GestAgro-Event: webhook.verification
X-GestAgro-Signature: sha256=...

{
  "type": "webhook.verification",
  "challenge": "random-string-to-echo-back",
  "webhook_id": "webhook_abc123"
}

Vous devez renvoyer le challenge dans votre réponse pour confirmer la configuration.

Sécurité et authentification

Vérification de la signature

Chaque webhook inclut une signature HMAC-SHA256 dans le header X-GestAgro-Signature. Vous devez vérifier cette signature pour vous assurer que la requête provient bien de GestAgro. 

// Python
import hmac
import hashlib

def verify_webhook_signature(payload, signature, secret):
    expected_signature = hmac.new(
        secret.encode('utf-8'),
        payload.encode('utf-8'),
        hashlib.sha256
    ).hexdigest()
    
    return hmac.compare_digest(f"sha256={expected_signature}", signature)

Bonnes pratiques de sécurité

  • Utilisez HTTPS pour votre endpoint de webhook
  • Toujours vérifier la signature avant de traiter l'événement
  • Idempotence : traitez chaque événement une seule fois (vérifiez l'ID)
  • Stockez votre secret de manière sécurisée (variables d'environnement)
  • Loggez tous les webhooks reçus pour le débogage

Logique de retry

Si votre endpoint retourne un code HTTP 2xx, l'API considère que le webhook a été traité avec succès. Sinon, l'API réessayera automatiquement selon le plan suivant :

Tentative Délai Durée totale
1 Immédiat 0s
2 5 minutes 5 min
3 15 minutes 20 min
4 1 heure 1h 20min
5 6 heures 7h 20min

Important : Votre endpoint doit répondre dans un délai de 10 secondes. Au-delà, la requête sera considérée comme ayant échoué et sera réessayée.
