Guide d'Authentification

Vue d'ensemble

L'API GestAgro utilise l'authentification JWT (JSON Web Tokens) pour sécuriser les endpoints. Vous devez obtenir un token d'accès avant de pouvoir utiliser la plupart des fonctionnalités de l'API.

1. Inscription

Créez un nouveau compte utilisateur. Vous recevrez automatiquement un token d'accès et un refresh token.

POST {{ api_base_url }}auth/register/ POST

Body:

{
  "email": "agriculteur@example.com",
  "password": "MotDePasse123!",
  "first_name": "Jean",
  "last_name": "Dupont",
  "user_role": "farmer",
  "phone": "+241 06 12 34 56 78"
}

Réponse (201):

{
  "message": "Utilisateur créé avec succès",
  "refresh": "eyJ0eXAiOiJKV1QiLCJhbGc...",
  "access": "eyJ0eXAiOiJKV1QiLCJhbGc...",
  "user": {
    "id": 1,
    "email": "agriculteur@example.com",
    "first_name": "Jean",
    "last_name": "Dupont",
    "user_role": "farmer"
  }
}

2. Connexion

Connectez-vous avec vos identifiants pour obtenir un nouveau token d'accès.

POST {{ api_base_url }}auth/login/ POST

Body:

{
  "email": "agriculteur@example.com",
  "password": "MotDePasse123!"
}

Réponse (200):

{
  "refresh": "eyJ0eXAiOiJKV1QiLCJhbGc...",
  "access": "eyJ0eXAiOiJKV1QiLCJhbGc...",
  "user": {
    "id": 1,
    "email": "agriculteur@example.com",
    "first_name": "Jean",
    "last_name": "Dupont"
  }
}

3. Utiliser le Token

Incluez le token d'accès dans l'en-tête Authorization de toutes vos requêtes authentifiées.

Format: Authorization: Bearer <access_token>

Exemple avec cURL:

curl -X GET "{{ api_base_url }}farmers/products/" \
  -H "Authorization: Bearer eyJ0eXAiOiJKV1QiLCJhbGc..." \
  -H "Content-Type: application/json"

Exemple avec JavaScript (Fetch):

fetch('{{ api_base_url }}farmers/products/', {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer ' + accessToken,
    'Content-Type': 'application/json'
  }
})
.then(response => response.json())
.then(data => console.log(data));

4. Rafraîchir le Token

Les tokens d'accès ont une durée de vie limitée. Utilisez le refresh token pour obtenir un nouveau token d'accès sans avoir à vous reconnecter.

POST {{ api_base_url }}auth/refresh/ POST

Body:

{
  "refresh": "eyJ0eXAiOiJKV1QiLCJhbGc..."
}

Réponse (200):

{
  "access": "eyJ0eXAiOiJKV1QiLCJhbGc..."
}

5. Vérifier le Token

Vérifiez si un token est valide sans le rafraîchir.

POST {{ api_base_url }}auth/verify/ POST

Body:

{
  "token": "eyJ0eXAiOiJKV1QiLCJhbGc..."
}

6. Déconnexion

Révoquez un refresh token pour déconnecter un utilisateur.

POST {{ api_base_url }}auth/logout/ POST

Body:

{
  "refresh": "eyJ0eXAiOiJKV1QiLCJhbGc..."
}

7. Mot de passe oublié

Démarrez un flux de réinitialisation de mot de passe en deux étapes: demande par email puis confirmation avec le token reçu.

Étape 1 — Demande de réinitialisation

POST {{ api_base_url }}auth/password/reset/ POST

Body:

{
  "email": "utilisateur@example.com"
}

Si un compte existe, un email est envoyé avec un lien sécurisé (uid + token).

Étape 2 — Confirmation

POST {{ api_base_url }}auth/password/reset/confirm/ POST

Body:

{
  "uid": "base64-user-id",
  "token": "token-de-securite",
  "new_password": "MotDePasseFort123!"
}

Le mot de passe est mis à jour après vérification du token.

Rôles Utilisateur

Chaque utilisateur a un rôle principal qui détermine ses permissions et accès aux fonctionnalités.

farmer

Agriculteur - Gestion de produits et ventes

buyer

Acheteur - Navigation catalogue et commandes

transporter

Transporteur - Gestion de flotte et expéditions

agronomist

Agronome - Gestion de champs et diagnostics

admin

Administrateur - Accès complet à la plateforme

Bonnes pratiques de sécurité

Recommandations importantes

  • Ne jamais exposer vos tokens dans le code source ou les repositories publics
  • Stockez les tokens de manière sécurisée (variables d'environnement, secrets managers)
  • Implémentez un rafraîchissement automatique des tokens avant expiration
  • Utilisez HTTPS en production pour protéger les tokens en transit
  • Révoquez immédiatement les tokens compromis via l'endpoint de déconnexion

Durée de vie des tokens

Type Durée Usage
Access Token 1 heure Toutes les requêtes authentifiées
Refresh Token 7 jours Rafraîchir l'access token
