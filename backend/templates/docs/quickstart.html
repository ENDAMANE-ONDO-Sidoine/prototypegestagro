Démarrage rapide

Commencez à utiliser l'API GestAgro en quelques minutes. Ce guide vous aidera à configurer votre environnement et à effectuer votre première requête.

1

Configuration de l'environnement

Base URL

L'API GestAgro est accessible à l'adresse suivante :

{{ api_base_url }}

Production

https://gestagro-api.onrender.com/api/v1/
2

Créer un compte

Créez un compte utilisateur pour obtenir vos identifiants d'accès.

POST {{ api_base_url }}auth/register/

{
  "email": "votre@email.com",
  "password": "MotDePasse123!",
  "first_name": "Prénom",
  "last_name": "Nom",
  "user_role": "buyer",
  "phone": "+241 06 12 34 56 78"
}

Rôles disponibles : farmer, buyer, transporter, agronomist

3

Obtenir un token d'accès

Connectez-vous pour obtenir un token JWT.

POST {{ api_base_url }}auth/login/

{
  "email": "votre@email.com",
  "password": "MotDePasse123!"
}

Réponse :

{
  "access": "eyJ0eXAiOiJKV1QiLCJhbGc...",
  "refresh": "eyJ0eXAiOiJKV1QiLCJhbGc...",
  "user": { ... }
}
4

Effectuer votre première requête

Utilisez le token dans l'en-tête Authorization pour faire des requêtes authentifiées.
