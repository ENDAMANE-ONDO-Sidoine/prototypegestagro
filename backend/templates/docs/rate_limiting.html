Limitation de taux (Rate Limiting)

L'API GestAgro utilise des limitations de taux pour garantir des performances optimales et une utilisation équitable de nos ressources pour tous les utilisateurs.

Quotas par défaut

1000

Requêtes par heure

Par utilisateur authentifié

100

Requêtes par minute

Burst limit

10

Requêtes par seconde

Pic maximum

Headers de réponse

Chaque réponse de l'API inclut des headers contenant des informations sur vos limites :

X-RateLimit-Limit

Nombre maximum de requêtes autorisées dans la période

X-RateLimit-Remaining

Nombre de requêtes restantes dans la période actuelle

X-RateLimit-Reset

Timestamp Unix (en secondes) du prochain reset du compteur

Retry-After

Nombre de secondes à attendre après une erreur 429

Dépassement des limites

Erreur 429 Too Many Requests

Lorsque vous dépassez votre limite, l'API retourne une erreur 429 avec les headers suivants : 

HTTP/1.1 429 Too Many Requests
X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 0
X-RateLimit-Reset: 1705320000
Retry-After: 3600

{
  "error": "rate_limit_exceeded",
  "message": "Vous avez dépassé votre limite de requêtes. Réessayez dans 3600 secondes.",
  "retry_after": 3600
}

Bonnes pratiques

  • Surveillez le header X-RateLimit-Remaining pour éviter de dépasser la limite
  • Implémentez une logique de retry avec backoff exponentiel lors d'une erreur 429
  • Utilisez le header Retry-After pour déterminer le délai d'attente
  • Mettez en cache les réponses lorsque c'est possible pour réduire le nombre de requêtes
  • Utilisez la pagination pour récupérer les données par lots plutôt qu'en une seule requête

Gestion du rate limiting dans votre code

JavaScript/Node.js

async function makeRequest(url, options) {
  const response = await fetch(url, options);
  
  // Vérifier les limites
  const remaining = parseInt(response.headers.get('X-RateLimit-Remaining') || '0');
  const resetTime = parseInt(response.headers.get('X-RateLimit-Reset') || '0');
  
  if (remaining < 10) {
    console.warn(`Attention: Il reste ${remaining} requêtes. Reset à ${new Date(resetTime * 1000)}`);
  }
  
  // Gérer l'erreur 429
  if (response.status === 429) {
    const retryAfter = parseInt(response.headers.get('Retry-After') || '60');
    console.log(`Rate limit atteint. Attente de ${retryAfter} secondes...`);
    await new Promise(resolve => setTimeout(resolve, retryAfter * 1000));
    return makeRequest(url, options); // Retry
  }
  
  return response;
}

Python

import time
import requests

def make_request(url, headers):
    response = requests.get(url, headers=headers)
    
    # Vérifier les limites
    remaining = int(response.headers.get('X-RateLimit-Remaining', 0))
    reset_time = int(response.headers.get('X-RateLimit-Reset', 0))
    
    if remaining < 10:
        print(f"Attention: Il reste {remaining} requêtes. Reset à {reset_time}")
    
    # Gérer l'erreur 429
    if response.status_code == 429:
        retry_after = int(response.headers.get('Retry-After', 60))
        print(f"Rate limit atteint. Attente de {retry_after} secondes...")
        time.sleep(retry_after)
        return make_request(url, headers)  # Retry
    
    return response
