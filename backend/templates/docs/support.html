Questions fréquentes (FAQ)

Comment obtenir un token d'accès ?

Vous devez d'abord créer un compte via POST /api/v1/auth/register/, puis vous connecter avec POST /api/v1/auth/login/. La réponse contiendra un access_token et un refresh_token.

Mon token a expiré, que faire ?

Utilisez votre refresh_token pour obtenir un nouveau token d'accès via POST /api/v1/auth/refresh/. Les tokens d'accès expirent après 1 heure, les refresh tokens après 7 jours.

Quelle est la limite de taux (rate limiting) ?

L'API limite à 1000 requêtes par heure par utilisateur. Si vous dépassez cette limite, vous recevrez une erreur 429 avec un header Retry-After indiquant quand vous pourrez refaire des requêtes.

Comment gérer les erreurs 500 ?

Les erreurs 500 sont des erreurs serveur temporaires. Implémentez une logique de retry avec un délai exponentiel. Si le problème persiste, contactez le support avec l'error_id fourni dans la réponse.

Puis-je utiliser l'API en production ?

Oui, l'API est disponible en production à l'adresse https://gestagro-api.onrender.com/api/v1/. Assurez-vous d'utiliser HTTPS en production et de stocker vos tokens de manière sécurisée.
