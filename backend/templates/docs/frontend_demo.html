Consommer l'API GestAgro depuis Next.js

Cette page rassemble des exemples concrets d'intégration de l'API côté frontend dans un projet Next.js. Chaque carte correspond à un acteur majeur de la plateforme. Cliquez sur la carte pour afficher un exemple d'utilisation (Server Action, chargement de métadonnées, mutation) ainsi que les endpoints à appeler.

  • Tous les exemples utilisent fetch côté serveur ("use server") afin de garder les tokens en cookies HttpOnly.
  • Les URL API sont résolues via process.env.NEXT_PUBLIC_API_URL (fallback sur la production Render).
  • Les métadonnées (/meta/) sont idéales pour alimenter les listes déroulantes, éviter les valeurs en dur et valider les entrées côté frontend.
