Installation et Configuration

Guide complet pour configurer votre environnement de développement et intégrer l'API GestAgro dans votre application.

Configuration de base

Base URL

Production: https://gestagro-api.onrender.com/api/v1/
Développement: http://localhost:8000/api/v1/

Headers requis

Content-Type: application/json
Authorization: Bearer YOUR_ACCESS_TOKEN

Variables d'environnement

Configurez ces variables dans votre fichier .env :

# API Configuration
GESTAGRO_API_URL=https://gestagro-api.onrender.com/api/v1/
GESTAGRO_API_KEY=your_api_key_here

# Authentification
GESTAGRO_CLIENT_ID=your_client_id
GESTAGRO_CLIENT_SECRET=your_client_secret

# Environnement
GESTAGRO_ENV=production  # ou 'development'

SDKs et Bibliothèques

JavaScript / Node.js

npm install axios
import axios from 'axios';

const api = axios.create({
  baseURL: '{{ api_base_url }}',
  headers: {
    'Content-Type': 'application/json'
  }
});

// Ajouter le token aux requêtes
api.interceptors.request.use(config => {
  const token = localStorage.getItem('access_token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

Python

pip install requests
import requests

class GestAgroAPI:
    def __init__(self, base_url, token):
        self.base_url = base_url
        self.headers = {
            'Authorization': f'Bearer {token}',
            'Content-Type': 'application/json'
        }
    
    def get(self, endpoint):
        return requests.get(
            f'{self.base_url}{endpoint}',
            headers=self.headers
        )

Configuration des requêtes

Timeout

Configurez un timeout approprié pour vos requêtes :

Timeout recommandé: 30 secondes

Retry Logic

Implémentez une logique de retry pour les erreurs temporaires :

Retry pour: 429, 500, 502, 503, 504
Nombre max de tentatives: 3
Délai entre tentatives: exponentiel (1s, 2s, 4s)

Test de connexion

Testez votre configuration avec cette requête simple :

GET {{ api_base_url }}
Authorization: Bearer YOUR_TOKEN

Si tout est configuré correctement, vous devriez recevoir une réponse avec les informations de l'API.
