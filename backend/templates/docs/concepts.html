Concepts de l'API GestAgro

Architecture REST

L'API GestAgro suit les principes REST (Representational State Transfer) pour offrir une interface cohérente et intuitive. Chaque ressource est accessible via une URL unique et peut être manipulée avec les méthodes HTTP standards : GET, POST, PUT, PATCH, DELETE.

Base URL: {{ api_base_url }}

Authentification JWT

L'API utilise JSON Web Tokens (JWT) pour l'authentification. Chaque requête doit inclure un token d'accès dans l'en-tête Authorization: Bearer <token>.

  • Les tokens ont une durée de vie limitée pour des raisons de sécurité
  • Utilisez le refresh token pour obtenir un nouveau token d'accès
  • Les tokens peuvent être révoqués lors de la déconnexion

Acteurs de la Plateforme

Agriculteurs

Gèrent leurs produits agricoles, catégories, stocks et reçoivent des commandes. Ils peuvent suivre leurs ventes et gérer leurs profils.

Acheteurs

Parcourent le catalogue, gèrent leurs paniers, passent des commandes et créent des listes de souhaits. Ils peuvent suivre leurs commandes et laisser des avis.

Transporteurs

Gèrent leur flotte de véhicules, créent des expéditions, suivent les livraisons et proposent des offres de transport aux autres acteurs.

Agronomes

Gèrent les champs, suivent les cultures, effectuent des diagnostics, donnent des recommandations et alertent sur les conditions météorologiques.

Organisations Multi-Tenants

La plateforme supporte un modèle multi-tenants où chaque utilisateur peut appartenir à plusieurs organisations. Les ressources sont automatiquement filtrées selon l'organisation de l'utilisateur.

  • Un utilisateur peut avoir plusieurs membreships dans différentes organisations
  • Chaque membership a un rôle (owner, admin, member, viewer)
  • Les permissions sont gérées au niveau de l'organisation

Pagination

Les listes de ressources sont paginées pour optimiser les performances. Utilisez les paramètres page et page_size pour naviguer dans les résultats. 

{
  "count": 100,
  "next": "{{ api_base_url }}products/?page=2",
  "previous": null,
  "results": [...]
}

Format des Réponses

Toutes les réponses sont au format JSON avec un encodage UTF-8. Les dates sont au format ISO 8601.

Format de date: 2025-10-29T14:30:00Z

Format monétaire: "1500.00" (string pour éviter les problèmes de précision)

Monnaie: XAF (Franc CFA) par défaut

Encodage: UTF-8

Filtrage et Recherche

La plupart des endpoints de liste supportent le filtrage et la recherche via des paramètres de requête.

Exemples de filtres

GET /api/v1/farmers/products/?status=active&category=legumes
GET /api/v1/buyers/orders/?status=pending&ordering=-created_at
GET /api/v1/search/products/?q=mais&page=1&page_size=20

Configurez vos webhooks via l'interface d'administration ou l'API pour recevoir des notifications en temps réel.
